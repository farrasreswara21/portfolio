What I've built

Projects I built at NucleusBI as a Data Engineer.

DutchVans

Vehicle listings data pipeline and client API

DutchVans wants a daily view of competitor listing prices and can access it through an API. Therefore, I started by designing the database, then built an ELT pipeline that runs every day. The pipeline scrapes data from competitor websites, loads it into a MySQL database, and transforms it, including deduplication and cleaning. The result is served through an API, built with FastAPI.

Telenet

Competitor price intelligence

To collect all of Telenet's competitors' internet, mobile, and TV prices, I helped build and maintain a large share of the competitor web scrapers. That meant automating address checks and bundle configurators with Playwright, extracting promotions, and keeping the scrapers running through site redesigns.

  • Python
  • Playwright
  • requests
Odido

Phone and plan price scraping

The objective is to track phone and subscription prices from a phone e-commerce site. My task was to help build a scraper that collects smartphone models with SIM subscriptions. I also set up the run automation with AWS Lambda and Batch jobs.

Eneco

Energy tariff comparison engine

Eneco needed to compare the cost of multiple Dutch energy suppliers every day. In this project, I helped build several supplier scrapers and collected the costs of electricity, feed-in, cashback, and gas from the websites' APIs.

TLFS

Lease price scraping across car brand websites

TLFS wants to track private-lease prices by contract length and mileage from multiple car brands. I took part by building scrapers for several car-brand websites. I also created Teams alerts that flag failed runs and suspicious data changes.
